# highland_sanctuary
Highland Sanctuary is a GenAI-powered travel discovery platform that redefines how travelers experience Northeast India. Built in Tezpur, Assam, it curates authentic, verified homestays, monastery retreats, tea bungalows, and eco-lodges across all eight states of the region: Assam, Meghalaya, Arunachal Pradesh, Nagaland, Manipur, Mizoram,ETC
